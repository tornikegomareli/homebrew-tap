# Homebrew Tap

This is a Homebrew tap for Tornike Gomareli's tools.

## Installation

```bash
brew tap tornikegomareli/tap
brew install apple-launcher-icons
```

Or install directly:

```bash
brew install tornikegomareli/tap/apple-launcher-icons
```

## Available Formulas

- **apple-launcher-icons**: Generate app icons for Apple platforms from a single PNG file
